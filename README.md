# Grist-Mooc

Un module d'auto-formation open source et centralisé pour maîtriser Grist en toute autonomie.

## À propos

**Grist-Mooc** est une initiative de la Métropole de Lyon qui offre une centralisation de l'ensemble des contenus open source existants produits par l'ANCT, la DINUM, Gris Labs et la Métropole de Lyon pour accompagner l'apprentissage de l'outil Grist.

Ce projet s'adresse à tous ceux qui souhaitent s'autoformer à Grist, qu'ils soient novices ou utilisateurs confirmés. C'est un espace d'apprentissage collaboratif et accessible qui met à disposition une documentation complète et des exercices pratiques.

## Comment utiliser Grist-Mooc

### Installation et Import

1. **Téléchargez** le fichier `Grist-Mooc.grist` depuis ce dépôt
2. Depuis votre instance Grist cliquez sur **Nouveau** puis **Importer un document**
3. **Commencez à apprendre** ! Le module est prêt à être utilisé en autonomie

### Rétro-compatibilité et Mises à jour

Grist-Mooc est conçu pour être **totalement rétro-compatible**. Peu importe quand vous avez téléchargé le fichier, vous pouvez toujours accéder aux mises à jour.

Dans la **section Conclusion** du fichier Grist, vous trouverez deux boutons simples vous permettant de :
- ✅ **Mettre à jour les exercices** pour accéder aux nouveautés de la dernière version
- ✅ **Télécharger les instructions** pour avoir à disposition la dernière version docx des explications

Cela signifie que tous les fichiers Grist-Mooc restent compatibles et à jour, sans besoin de réimporter le fichier.

## Contenu du module

Le module couvre :
- Les concepts fondamentaux de Grist
- Le typage des données 
- La manipulation et le fonctionnement des vues
- La manipulation et le fonctionnement des références
- La création et l'utilisation de formules
- La création de permission avancées
- Les bonnes pratiques

Chaque section est conçue pour permettre un apprentissage autonome et fluide.
